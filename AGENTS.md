
## Languages
- Use TypeScript and Rust.

## Libraries
- You can freely install necessary libraries.
- Use `cargo add` to install Rust libraries.
- Use `npm install` to install TypeScript libraries.

## Formatter and Linter
- Use Biome for TypeScript formatting and linting (`npm run format`, `npm run lint`, and `npm run check`).
- Use rustfmt for Rust formatting (`cargo fmt`) and Clippy for Rust linting (`cargo clippy`).
- Keep changes automatically made by formatter, including changes outside the immediate task scope.
