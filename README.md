# Browser

A macOS web browser MVP for functional testing. It provides a native WebView, Back and Forward buttons, and a combined URL and search bar.

This is an early test version. Apple passkey support is pending entitlement approval.

[Download the MVP for macOS (Apple Silicon)](https://github.com/KeisukeMiyamoto1324/browser-mvp/releases/tag/v0.1.0-mvp.1).
